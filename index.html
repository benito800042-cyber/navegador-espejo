    Contenido reflejable

    Esta tarjeta y el vídeo de prueba se pueden invertir horizontalmente. Pulsa Modo espejo para comparar. Los controles permanecen operables en modo normal.

    Limitación técnica: una web no puede mostrar cualquier sitio externo dentro de este visor. Algunos servidores bloquean iframe (X-Frame-Options/CSP), y el navegador impide leer o modificar contenido de otros dominios por seguridad (CORS). Navegador Espejo no intenta saltarse esas restricciones, ni las de YouTube o DRM.

    Controles

    En modo espejo se invierte visualmente el área visible. Los controles siguen disponibles, pero para manejarlos con comodidad pulsa otra vez y vuelve al modo normal.

    Uso responsable

    • Solo con el vehículo completamente detenido.
    • No usar durante la conducción ni para distraerse.
    • El visor es una prueba local: no proxyfica ni altera webs protegidas.
